## Key Technical Insight

**Panel Window Level Control:**
Panel-type windows on macOS default to a higher window level that keeps them above normal windows, regardless of the `alwaysOnTop` boolean setting. The `setAlwaysOnTop()` method accepts a second parameter to explicitly set the window level:

```javascript
this.mainWindow.setAlwaysOnTop(false, 'normal')
```

The `'normal'` level allows the panel to participate in standard z-order behavior, behaving like a regular window while maintaining the panel window type. This enables the desired behavior: a panel-style window that doesn't float persistently above all other windows.

## Technical Notes

### Window Levels on macOS

Electron exposes several window levels via the second parameter of `setAlwaysOnTop()`:
- `'normal'` - Standard window level, participates in normal z-order
- `'floating'` - Floats above normal windows (default for panel type)
- `'torn-off-menu'` - Menu-level floating
- `'modal-panel'` - Modal level
- `'main-menu'` - Main menu level
- `'status'` - Status bar level
- `'pop-up-menu'` - Pop-up menu level
- `'screen-saver'` - Screen saver level

The panel window type is useful for utility windows but requires careful level management to avoid unintended always-on-top behavior.
