**What maps cleanly**
- Toolbar, breadcrumb, list/grid/column views, sort, search — all directly applicable
- Collections → sidebar favorites/locations analog
- Object name, type, date → file metadata columns
- Status bar (N items, selection count) — exact port

**Where the contradiction surfaces naturally**
- *Location*: In HFS, an item has exactly one path. Index objects have zero, one, or many sources — the breadcrumb has nowhere to point by default. This is visible immediately.
- *Hierarchy*: Collections are flat and non-exclusive. You can't build a real folder tree from them. The sidebar will look like Finder's sidebar but refuse to nest.
- *Multi-device sources*: A file "lives" somewhere. An Index object with sources on two devices lives nowhere and everywhere. The path column breaks down.
- *URLs*: No parent folder. The breadcrumb is meaningless.

**One open question before building**

What does the root view represent — all objects with no filter applied (flat, no hierarchy at all), or do we construct a pseudo-hierarchy from tags/collections to see how far that fiction can be maintained before it collapses?

I'd argue for starting **flat** (root = all objects, no hierarchy), with full file browser chrome. Let the user experience the absence of hierarchy as a fact, not a design statement. The graph view later becomes the answer to what was missing, not a critique delivered upfront.

Do you want to proceed on that basis, or is there a structural hierarchy you want to impose first?

Main layout shell. On mount: call loadAll() and subscribeToLive() from the store. Manages: selectedId (string|null), searchQuery (string), sortKey ('created_at'|'name'|'sources'), sortDir ('asc'|'desc').

displayObjects = objects filtered by searchQuery (case-insensitive name match), sorted by sortKey/sortDir. Default: sortKey='created_at', sortDir='desc' (newest first).

handleSort(key): if same key, flip dir; if new key, set dir to 'desc' for created_at else 'asc'.

allCollections = [systemAll, ...collections sorted by order].
activeCollection = allCollections.find matching activeCollectionId, fallback to systemAll.

Layout (flex row, fills parent):
- `<BrowserSidebar collections={allCollections} activeCollectionId={activeCollectionId ?? systemAll.id} onSelect={toggleCollection} />`
- div.file-browser-main (flex col):
  - `<BrowserToolbar locationName={activeCollection.name} searchQuery onSearchChange />`
  - div.file-browser-content (flex 1, overflow hidden):
    - loading && objects.length===0 → div.browser-empty "Loading..."
    - displayObjects.length===0 → div.browser-empty "No objects"
    - else → `<ObjectListView objects={displayObjects} selectedId onSelect={setSelectedId} sortKey sortDir onSort={handleSort} />`
  - `<BrowserStatusBar count={displayObjects.length} />`

### src/components/ObjectListView.jsx
The list. Two parts: sticky column header row + scrollable body.

Columns array:
- { key: 'name', label: 'Name', flex: 1 }
- { key: 'created_at', label: 'Date Added', width: 160 }
- { key: 'sources', label: 'Sources', width: 72, align: 'right' }
- { key: 'kind', label: 'Kind', width: 140 }

Header: div.list-header — one div.list-header-cell per column. Clicking a header cell calls onSort(col.key). Show sort indicator (↑ or ↓) on the active sortKey column.

Body: div.list-body — one div.list-row per object. Click toggles selection (click selected → deselect). Row has selected class when selectedId === obj.id.

Each row has four div.list-cell children:
1. name-cell: SVG icon + span.row-name showing obj.name || '(untitled)'
2. formatDate(obj.created_at) — M/D/YY, H:MM AM/PM format
3. obj.sources?.length ?? 0 — right aligned
4. getKind(obj) — infer from sources

Helper getKind(obj):
- no sources → '—'
- multiple sources → 'Multiple'
- uri starts with http → 'URL'
- else: check extension: pdf→'PDF Document', md→'Markdown', txt→'Plain Text', jpg/jpeg→'JPEG Image', png→'PNG Image', gif→'GIF Image', mp3/wav→'Audio', mp4/mov→'Video', zip→'Archive', js→'JavaScript', ts→'TypeScript', py→'Python', json→'JSON', html→'HTML', css→'CSS', sh→'Shell Script', default→'Document'

Helper formatDate(iso): toLocaleString 'en-US' with month:'numeric', day:'numeric', year:'2-digit', hour:'numeric', minute:'2-digit'.

SVG icons (inline):
- URL object (first source starts with http): globe icon (circle + meridian lines)
- File object: document with folded corner icon
- No sources: generic box/square icon
