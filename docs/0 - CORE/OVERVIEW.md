# Index — Project Overview

**Index** is a **local-first, personal information management application** for organizing and connecting digital objects across your machine.

## The Core Problem

Traditional file systems force information into rigid hierarchies. A research paper belongs in multiple contexts (a project folder, bookmarks, notes, links), but you can only store it in one place. Index solves this by creating a semantic layer that lets objects exist in *many* contexts simultaneously through tagging and linking.

## What It Does

Index lets you:
- **Index anything with a URI** — local files, URLs, future extensibility to Notion/Obsidian
- **Tag dynamically** — apply unlimited labels without moving originals
- **Collect intelligently** — create smart folders based on tag logic (AND/OR/NOT queries)
- **Link explicitly** — draw relationships between objects to visualize your information graph
- **Search semantically** — find by *what things mean*, not where they're stored

## Key Architecture Principles

1. **Objects Over Locations** — Identity is independent of storage
2. **Tags Over Folders** — Multi-dimensional organization instead of hierarchies
3. **References Over Copies** — Index points to sources; originals never move
4. **Local Over Cloud** — Complete data ownership, no accounts or sync

## Current State (v0.3)

The application supports file and URL indexing with a cleaned-up architecture, tagging system, collections, linking, and a graph visualization interface. Git history shows it's matured through UI refinements and has moved past electron integration to a more stable foundation.

Index is fundamentally a tool for managing contextual relationships in your digital life, replacing hierarchical file systems with semantic, graph-based organization.
