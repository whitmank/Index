# Development Log - 2026-03-04

## Session Summary

Added a tabbed settings modal with window behavior profiles (overlay vs. window), persisting bounds and restoring on launch. Fixed a bug where opening an object source was hiding the app window. Version bumped to 0.3.0, sourced dynamically from package.json.

## Activities Completed

- Fixed `app:openSource` handler in `electron/main/ipc/db-handlers.js` — removed erroneous `mainWindow.hide()` call so the app stays visible after opening a source URI
- Added tabbed settings modal with General and Window Behavior tabs
- Introduced window behavior profiles: `overlay` (existing panel behavior) and `window` (frameless, centered, no traffic lights)
- Created profiles architecture under `electron/main/window-manager/macos/profiles/` — each profile is a separate file exporting base BrowserWindow options
- macOS platform driver (`electron/main/window-manager/macos/index.js`) applies macOS-specific overrides (type: panel, collectionBehavior) on top of profile base options
- Window profile persists bounds (position + size) to `~/.index/window-settings.json`; restores on launch with screen validation to handle display changes
- Profile switcher in settings recreates the window immediately on change
- Removed `generic.js` window manager — macOS-only scope for now
- Bumped version to `0.3.0`; exposed via Vite `define` as `__APP_VERSION__` sourced from `package.json`

## Files Changed

- `electron/main/ipc/db-handlers.js` - Removed `mainWindow.hide()` from `app:openSource` handler
- `electron/main/window-manager/macos/index.js` - Platform driver applies profile base + macOS overrides
- `electron/main/window-manager/macos/profiles/overlay.js` - New: overlay profile (panel behavior)
- `electron/main/window-manager/macos/profiles/window.js` - New: window profile (frameless, centered)
- `electron/main/window-manager/generic.js` - Removed
- `src/components/SettingsModal.jsx` - Added General / Window Behavior tabs and profile switcher UI
- `vite.config.js` (or equivalent) - Added `define: { __APP_VERSION__ }` sourced from `package.json`
- `package.json` - Version bumped to `0.3.0`

## Key Decisions

- **Profiles as separate files**: Keeps each window configuration self-contained and easy to extend with future profiles without modifying the driver
- **Platform driver owns macOS overrides**: Separation between "what the profile wants" and "what macOS requires" — profiles stay platform-agnostic
- **Bounds persistence in `~/.index/window-settings.json`**: Follows existing local-first data pattern; screen validation on restore prevents off-screen windows after display changes
- **Removed generic.js**: Simplifies the window manager — macOS is the primary target for now; re-introduce when cross-platform work begins
- **`__APP_VERSION__` via Vite define**: Single source of truth in `package.json`; no manual sync required in UI code
