## Key Decisions

- **Simplified file path resolution**: After initial complexity with path manipulation, adopted Electron's `webUtils.getPathForFile()` as the canonical solution. This API is specifically designed for converting File objects to paths in Electron apps.
- **Unified paste handler**: Combined file paste, text path paste, and URL paste into single handler that intelligently detects input type and populates source field accordingly.
- **Keyboard shortcuts in custom hook**: Extracted shortcuts to `useKeyboardShortcuts.js` for maintainability and to prevent App.jsx from becoming monolithic.
- **Visual feedback pattern**: Used centered overlay with pointer-events-none for drop indicator, ensuring it doesn't interfere with drop events while providing clear user feedback.

## Technical Notes

### Drag-and-Drop Implementation
- Used `onDrop`, `onDragOver`, and `onDragLeave` handlers on App component
- `preventDefault()` required on dragOver to enable drop
- `e.dataTransfer.files[0]` provides the File object
- `window.api.getFilePath(file)` converts to absolute path string

### Clipboard Paste Implementation
Three scenarios handled in paste event:
1. **File paste**: `e.clipboardData.files.length > 0` - User copied file in Finder
2. **Text paste**: Check if text is file path (`startsWith('/')`) or URL (`http://` or `https://`)
3. All cases populate `source` field and trigger `setIsAddingObject(true)`

### Keyboard Shortcuts
- Platform-aware: Uses `metaKey` on macOS, `ctrlKey` on Windows/Linux
- Event listener attached to `document` with cleanup on unmount
- Cmd+O opens new object form
- Escape closes active forms (object creation, deletion confirmation)

### Electron Security Context
- `webUtils.getPathForFile()` only available in main process
- Exposed via preload script with contextIsolation enabled
- API surface: `window.api.getFilePath(file)` returns Promise<string>
